# htmx 4 with `prefix: ""` against the default prefix

## What was measured

The page and the driver of 2026-10-26T1750Z (C++ on webview/webview,
WebKitGTK 2.52.6, Xvfb). htmx 4.0.0 minified with the ascaridol
extension. The arms differ only in the htmx-config meta tag:

- default: `{"history":false}`, so htmx also reads `data-hx-` names.
- default2: the same page in a second file, for the A/A noise floor.
- empty: `{"history":false,"prefix":""}`, so htmx reads `hx-` names only.

Each run: three rounds, each round 50 warm-up and 500 timed clicks
with the real bridge (`htmx_bridge`), then with a JS bridge that
returns at once (`htmx_fake`). Five runs per arm, the three arms
alternated. Unit: microseconds per request, from the click to the
change of the target.
